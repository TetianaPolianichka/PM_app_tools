# Onboarding benchmark

## Flow metrics (count the same way for us and for each competitor)
- steps to first value (time-to-value);
- total number of taps;
- number of required fields;
- number of permission requests;
- position of the paywall and sign-up in the flow.

## Comparison table with the top 3
Columns: app | screens | steps to value | taps | permissions | sign-up position | paywall position | skip | progress | personalization | paywall type.

## Matching
- For each of our friction points: how competitors solve it, who does it better and how exactly.
- What competitors do worse than us — these strengths must be kept ("What to keep" section).
- Count how many competitors do better on each item: this is needed for condition (b) in the `audit-scoring` skill.
